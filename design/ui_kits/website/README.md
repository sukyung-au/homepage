# Website UI kit
Corporate marketing site built from the system's components. Screens: Home (tile stack), Operations → Assets (search, filter chips, utility-card grid, sticky data-request bar), Sustainability (photographic QuoteCard, airy lead, dark stat tile).
Click GlobalNav items to switch screens; click asset cards to add them to the sticky bar.
All imagery is placeholder (MediaFrame) — replace with real photography. Figures are illustrative.
No source product was supplied; screens follow the system's documented structure rather than an existing site.
