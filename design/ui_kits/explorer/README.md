# Exploration website UI kit
"OIL & GAS DEVELOPMENT — From Subsurface to Field Development". Scientific-exploration site: the homepage is one vertical journey through nine stages.
- index.html — Homepage: hero, stage index, 9 scenes, sticky StageNav (updates on scroll; click to jump)
- Storyboard.html — scene-by-scene IN / HOLD / OUT transition concepts + depth profile
- Technical.html — representative chapter: 02 Petroleum System
- DesignSystem.html — palette, type, controls, visualization, navigation, layout
Motion is NOT implemented. Every scene section carries data-stage, data-scene, data-depth, data-transition-in, data-transition-out and data-persist for later scroll-driven work.
Photos are drop-in image slots; technical visuals are procedural TechViz stand-ins. All figures are illustrative.
